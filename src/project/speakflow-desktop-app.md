Worked with the [Speakflow](/org/speakflow/) team to develop a
[desktop app](https://www.speakflow.com/download) to complement the web version.

## My Role

My main responsibility was creating the initial Tauri prototype and then
refining it to the point where it is now a working version. The app was
originally written with plain HTML and TypeScript before moving to React. The
desktop application now uses with React and Tailwind.

## What I Worked On

- Added the transparency system so that people can see through the script.
- Researched local transcription to see how we could bring transcription
  directly to the user's computer.
- Coordinated with designers and marketers to develop Speakflow from a purely
  web version to a multi-platform system.

## Current Status

Current work on version 3 and working on design for version 4.
